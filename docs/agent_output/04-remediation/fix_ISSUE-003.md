## 3. Why this is the smallest correct diff

Apply the CWE-943 catalog pattern by replacing the StringBuilder-built BasicQuery with Spring Data Criteria and Query construction. Bind department as an equality value, and where name search remains substring-based, use Pattern.quote on the supplied name so it is treated as literal text rather than caller-controlled regex syntax. This changes the query-construction sink itself, preventing input from becoming MongoDB operators or document structure instead of attempting to blacklist particular payload characters.

**Catalog pattern (`CWE-943`):** Improper Neutralization of Special Elements in Data Query Logic (NoSQL/SQL Injection)
