## 3. Why this is the smallest correct diff

Apply the CWE-770 catalog pattern by replacing unbounded repository reads with database-backed bounded retrieval. The scheduler REST path must use Spring Data Pageable with a server-enforced maximum page size, while the scheduled gender operation must retrieve only matching records through a database query. The report flow must process employee data in pages or as a stream and avoid retaining a complete result set and workbook payload together, so memory use does not scale with the entire collection.

**Catalog pattern (`CWE-770`):** Allocation of Resources Without Limits or Throttling
