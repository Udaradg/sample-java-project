# Step 05 — QA + Build Gate

Deterministic gates run by **`05_additional-test-execution`** against every change a diff was
captured for (Compiled or Compile Failed alike — both gates compile the project themselves,
independently of the Developer's own separate check):

- **QA gate** (`qa_<id>.md`) — drafts one new regression test (mocked, not database-backed — this
  repo has no embedded-database test dependency) and runs it inside an isolated `git worktree`.
- **Build gate** (`build_<id>.md`) — runs `mvn verify` plus a dependency-tree diff inside another
  isolated `git worktree`. **No agent-authored content at all** — every line comes straight from
  the gate script (deterministic CI/CD execution, not open-ended agentic reasoning).

## Reading Status

- **Passed** — ran for real and exited 0.
- **Failed** — something exited non-zero, or the diff/test diff didn't apply. Never overridden.
- **Refused** — the linked development report's Status was `Refused` (the Developer never captured
  a diff at all).

A `SKIPPED` individual QA test inside a Passed report means this sandbox lacks the dependency that
test needs — it is not counted as a failure, but it is not a pass either.
