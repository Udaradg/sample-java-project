## 3. Why this is the smallest correct diff

Replace EmployeeSearchRepository.searchEmployees's StringBuilder-built BasicQuery with a parameterised Criteria query, applying the catalog's CWE-943 canonical_approach to this repository's Spring Data MongoDB stack: Criteria.where("name").regex(Pattern.quote(name)), optionally chained with .and("department").is(department), executed via a Query wrapping that Criteria instead of a BasicQuery built from concatenated strings. Pattern.quote() ensures the name value is matched as a literal substring rather than as caller-supplied regex or query-operator syntax, which is what removes the caller's ability to inject structure — not just today's reported payload shapes. The department value is already a scalar match (`.is(...)`), which Criteria binds directly with no string interpolation at all.

**Catalog pattern (`CWE-943`):** Improper Neutralization of Special Elements in Data Query Logic (NoSQL/SQL Injection)
